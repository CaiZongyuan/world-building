# 审批时看什么

你在整个流程里只出场三次。每次都有明确要看的几样东西，看完了就可以点头。

## 需求访谈：三张清单

- [ ] **场景**：区域和设备齐不齐？有没有你心里有、清单上没有的设备？
- [ ] **流程**：每一步在哪里、由谁做、搬什么？顺序对不对？
- [ ] **资产**：哪些复用、哪些新建？复用的是否**实查过**（能编译、不缺文件），而不是只看了说明文档？
- [ ] **不做什么**：范围之外的东西是不是写清楚了？

## 审批点①：方案预览

方案页在仓库的 `proposals/<项目>/index.html`，可以直接在浏览器里打开。

- [ ] **运动学预演是否全部通过？** 报告分 G（夹爪行程）、P（取放位姿）、D（门和抽屉扫掠）、T（过渡）四类。失败过的项是怎么解决的？
- [ ] **布局里的取放高度**是否落在机器人可解的高度带里？取、放是否都让手爪径向朝外？
- [ ] **每台设备**的「复用 / 新建」、状态、难度等级、许可是否写清楚？只编译通过的设备不能写成 PASS。
- [ ] **风险一节**有没有你担心但没写的？
- [ ] **工程决策**有理由和证据吗？（不需要你逐项确认，看是否讲得通即可）

效果图只是概念图，不是工程图，不必纠结细节。

## 审批点②：plan + 参考图

审批页在项目的 `04-reference/index.html`（由 `wb review` 生成）。

- [ ] **你在意的每个风险，有没有一条带编号的门限对应？**
- [ ] **每条关键门限有没有负例？** 负例做过危险探针吗？（确认这个「错」在操作范围内真的危险）
- [ ] **哪些地方计划理想化？** 每一处是否都有门限盯住？
- [ ] **参考图和设计不一致的地方**是否逐张注明？
- [ ] **尺寸表**每一项是否都标了来源类别（标准锚点 / 设计假设 / 实测）？
- [ ] **大项目**：分期是否合理，每期的门限和负例是否标清楚？

点头之后，建模、仿真、渲染都由 agent 自主推进。

## 推进过程中：两个文件就够

| 文件 | 看什么 |
|---|---|
| `gates/<阶段>.json` | 每道门最近一次的判定、每项检查的状态和证据文件路径 |
| `stage-log.md` | 每个阶段一行实测数据（耗时、轮数、门失败、返工、人工介入、主要卡点），下面是卡点小节 |

大项目开发中途还会有进展截图（`progress/*.webp`）。想知道进展，直接问「现在进展到哪了」即可。

## 交付时

- [ ] 成片：不加速、不剪辑；理想化之处（教学时长、模拟数据）在字幕里标明。
- [ ] 渲染门 V1–V4 全部 PASS。
- [ ] 汇总复盘：哪个阶段问题最大，根因是什么，流程改了什么。
- [ ] 新经验已写回 `docs/lessons/` 和 skill。
