# 核心概念

这一页把流程里反复出现的词讲清楚。术语以仓库根目录的 `GLOSSARY.md` 为准；skill、经验记录和阶段日志里都用同一套词。

## 项目、阶段、工艺步骤

**项目**是流程的一次运行，对应一个具体场景，例如「细胞传代黑灯实验室」。**阶段**是流程里固定的一段：需求访谈、方案预览、plan、参考图、建模、仿真、渲染。**工艺步骤**是场景里实验工艺的一步，例如「开培养箱取板」「离心」。

后两个很容易混：「仿真阶段」是流程的一段；「第 6 步离心」是工艺的一步。全流程实验室有 7 个阶段、14 个工艺步骤。

**黑灯实验室**指无人值守、由机器人和自动化设备完成全部工艺步骤的实验室。**薄切片**是只含一个工艺步骤、但走完全部阶段的最小项目，用来测量每个阶段的真实成本。

## 验证门：五种结果

**验证门**是一个脚本：读项目目录里的产物，对照冻结的门限，给出 PASS / FAIL / NOT_RUN / BLOCKED / IDEALIZED 之一，并把判定和证据写进 `gates/<阶段>.json`。它不需要人参与，退出码 0 只代表 PASS。

一道门由若干项检查组成，合并成一个结果的规则是：**FAIL 优先于 BLOCKED，优先于 NOT_RUN，优先于 IDEALIZED，全部通过才是 PASS**。下面可以亲手试：点每一项的状态切换它，看整道门怎么判、命令行输出什么。

<GateSandbox />

两条容易忽略的规则：

- **IDEALIZED 永远不算 PASS。** 靠理想化才过的检查，必须在报告和成片里标明。
- **部分没跑也不能算 PASS。** 有一项 NOT_RUN，整道门就是 NOT_RUN。

每个阶段的检查都同时配有正例和负例夹具（`tests/fixtures/`），用 `uv run --extra sim pytest` 跑，保证验证门自己不出错。

## 审批点

**审批点**是阶段之间必须由人看过并点头才能继续的位置，一共两个：方案预览之后（①）、参考图之后（②，plan 和参考图一起审）。此外，需求访谈里要你确认三张清单，但那仍算需求访谈的一部分，不另设审批点。

审批点和验证门是两回事：验证门由脚本判定，不需要人；审批点只问方向性的问题。详见[谁决定什么](./roles)。

## 门限冻结

plan 阶段把「做成了」写成带编号的数字：S（仿真）、M（建模）、R（参考图）、V（渲染），加上负例 N。它们同时写进 `plan.md` 和机器可读的 `03-plan/thresholds.json`，并注明冻结日期。之后：

- 验证门只读 `thresholds.json`；
- 实测值不达标就改设计或做法，**不改门限**；
- 测量代码写错了就改代码，不改门限（薄切片 01 的 S8、S11 各改过一次测量代码）；
- 设计变了导致目标值跟着变（例如台面高度改了），要在 `revisions` 里写明原因，容差不变。

## 名义流程与负例

**名义流程**是按设计正常执行的那一次运行。**负例**是故意做错一件事的变体，门限必须判 FAIL。只看到 PASS 还不够：如果测量代码写错了，或者门限定得太松，任何情况都会判 PASS。负例就是用来证明门限真能分辨对错的。

## 难度等级与保真度

方案预览里，每个工艺步骤和设备都要标**难度等级**：

| 等级 | 含义 | 例子 |
|---|---|---|
| L1 | 刚体放置 | 预静置、机器人回停靠位 |
| L2 | 关节设备 | 门、抽屉、离心机盖由执行器驱动 |
| L3 | 抓取接触 | 夹住六孔板搬运、放板 |
| L4 | 精细接触或柔性 | 装吸头、旋盖 |
| L5 | 液体（只能符号化） | 吸液、排液 |

还要标**保真度**：物理（真实接触物理）、理想化、符号化。**理想化**指被显式标注为不做真实接触物理的步骤或部件状态，例如几克重的小件用 weld 约束代表「已夹住」。理想化允许用，但永远不计为 PASS，而且必须有门限盯住它（例如 S14 挂约束前必须对准、S15 挂上时不许跳变）。

## 阶段日志、阶段复盘、经验记录

- **阶段日志**（`stage-log.md`）：项目内逐阶段记录实测耗时、agent 轮数、验证门失败、返工、人工介入和主要卡点。**只记实测，不写时间预估。**
- **阶段复盘**：每个阶段结束后基于阶段日志的回顾。
- **经验记录**（仓库 `docs/lessons/`）：跨项目沉淀的流程知识，每个阶段一份：这一步做什么 → 输入 / 产物 / 完成判据 → 工具 → 标准做法 → 踩过的坑 → 阶段日志摘要。项目收尾时，新经验写回这里和 skill。

阶段日志是找出「哪一步问题最大」的唯一依据。薄切片 01 正是靠它发现了仿真阶段的返工大多可以前移，见[阶段复盘](/stages/phased#retro)。
